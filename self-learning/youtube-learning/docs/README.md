# YouTube Learning

A small React + Vite app that lists curated YouTube channels for frontend and JavaScript learning.

## Run

```bash
cd self-learning/youtube-learning
bun install
bun run dev
```

## What it does

- Lists channels sorted by `priority` (1 = top)
- Filters by tag with a custom dropdown
- Opens a slide-in sheet with overview, tags, and channel link
