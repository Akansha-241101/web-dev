# Backend Day 2 — Express intro

Same idea as Backend Day 1, but with **Express**. Still only **2 routes**.

## Routes

- `GET /` → `{ "message": "Home" }`
- `GET /hello` → `{ "message": "Hello" }`

## Run

```bash
cd backend/day-2-express-intro
npm install
npm start
```

```bash
curl http://localhost:5000/
curl http://localhost:5000/hello
```
