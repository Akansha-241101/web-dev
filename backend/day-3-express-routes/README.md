# Backend Day 3 — Express routes

**2 routes** with a small cars list. Learn route params (`:id`).

## Routes

- `GET /cars` → all cars
- `GET /cars/:id` → one car

## Run

```bash
cd backend/day-3-express-routes
npm install
npm start
```

```bash
curl http://localhost:5000/cars
curl http://localhost:5000/cars/1
```
