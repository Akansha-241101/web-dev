# PRD — What we are building

ShopNow is a simple shoe storefront (Nike, Adidas, Puma, Vans).
Browse products, filter them, and add available items to a cart. Dark theme by default.

## Goals

- Show all products with image and price
- Filter by brand, category, color, price, availability
- Add / remove cart items and see total
- Product detail page (later)
- Switch price between INR and USD (later)
- Light / dark theme toggle (later)
- Checkout screen is only a mock — no real payments

## Not in this project

- Real payments
- Login / accounts
- Backend or database
- Admin panel

## Must work

- All products render from the local catalog
- Unavailable products look muted and cannot be added to cart
- Cart total uses the selected currency
- Usable on mobile

## Done when

1. Foundations (theme, fonts, docs) ← current
2. Browse page (grid + filters)
3. Detail page + cart
4. Polish (empty states + checkout mock)
